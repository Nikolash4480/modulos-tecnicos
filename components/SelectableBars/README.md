Columnas grises de altura proporcional; la seleccionada se oscurece y se enmarca.

**Props:** `data` ({ label, value, selected? }[]): Columnas; `height` (number): Alto máximo de columna; 120 por defecto.
**Cuándo:** Elegir un día o categoría dentro de una serie corta en informes monocromos.
**Evitar:** Más de 12 columnas; varias seleccionadas juntas.
