Cuadrícula de dos columnas para muestrear fuentes: nombre en mayúsculas con su peso y una etiqueta mono debajo, sobre fondo naranja con filetes.

**Props:** `items` ({ name, weight?, label }[]): Celdas; `weight` numérico y `label` con el nombre del peso.
**Cuándo:** Mostrar candidatas de tipografía o variantes de un título en láminas de marca.
**Evitar:** Más de ocho celdas; usarla con fondos que no sean `accent`.
