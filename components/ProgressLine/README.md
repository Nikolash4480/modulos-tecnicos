Barra delgada (parte naranja, resto oscuro) sobre una fila mono con etiqueta, flecha y valor.

**Props:** `label` (string): Etiqueta (PROGRESO); `value` (number): Porcentaje 0–100; `display` (string): Texto del valor si difiere del porcentaje; `arrow` (boolean): Flecha entre etiqueta y valor; true por defecto.
**Cuándo:** Avance de una tarea o de un módulo en documentos técnicos.
**Evitar:** Varias barras apiladas sin etiqueta; escalas sin unidad.
