Rótulo de dos líneas con un bloque oscuro que aloja el triángulo de aviso.

**Props:** `label` (string): Primera línea (categoría); `sub` (string): Segunda línea (Advertencia).
**Cuándo:** Señalar una alerta de un informe, al borde inferior de la pantalla.
**Evitar:** Usarlo para errores de formulario (usa el texto `danger`).
