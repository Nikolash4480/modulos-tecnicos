Franja de barras de ancho variable en naranja y tinta, con un rótulo de código y su regla debajo.

**Props:** `code` (string): Código en el rótulo; `seed` (number): Semilla de las barras; `count` (number): Cantidad de barras; 46; `width` (number): Ancho; 320; `height` (number): Alto de las barras; 44.
**Cuándo:** Cabecera decorativa de una lámina técnica.
**Evitar:** Esperar que se pueda escanear: es solo ornamento.
