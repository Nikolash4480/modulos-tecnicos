Loseta cuadrada de esquina superior derecha cortada, con un código en mono al centro.

**Props:** `code` (string): Código (“2.C”); `tone` ('tile' | 'light' | 'accent'): Color; `size` (number): Lado; 160 por defecto.
**Cuándo:** Elegir módulos o niveles en fichas técnicas; `light` con texto naranja como estado activo.
**Evitar:** Texto de más de cuatro caracteres.
